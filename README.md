# Form đăng ký người dùng - CodeGym

Repository độc lập cho bài thực hành **Tạo giao diện form đăng ký người dùng**.

## Nội dung

- `index.html`: Form đăng ký người dùng với các trường họ và tên, email, số điện thoại, giới tính.
- `style.css`: Giao diện và bố cục của form.

## Yêu cầu kỹ thuật

- `action="http://demo.codegym.vn/6/registration_form/register.php"`
- `method="POST"`
- Họ và tên: `name="name"`
- Email: `name="email"`
- Số điện thoại: `name="phone"`
- Giới tính: `name="gender"`

## Chạy bài

Mở file `index.html` bằng Chrome hoặc Microsoft Edge.

## Lưu ý

Endpoint là máy chủ mẫu do đề bài cung cấp. Máy chủ có thể đã ngừng hoạt động hoặc trả về lỗi. Form được giữ đúng `action`, `method` và các thuộc tính `name` theo yêu cầu bài tập.
